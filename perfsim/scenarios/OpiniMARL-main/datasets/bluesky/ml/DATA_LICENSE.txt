Provenance
----------

This dataset was generated by the authors of this repository for the research
project described in:

* Seier, L., Kaplowitz, B., Towers, S., Bailey, R., & Foerster, J. (2026).
  Modelling Opinion Dynamics at Scale with Deep MARL. arXiv:2606.07487.

The dataset is a processed, derived, and anonymised representation of a
Bluesky interaction network. It is distributed as a weighted adjacency matrix
for research and benchmarking purposes.

What is included
----------------

* An anonymised adjacency matrix representing network relationships.
* Numerical edge weights derived from processed interaction data.

What is not included
--------------------

* Bluesky posts, reposts, replies, quotes, text, images, or media.
* Direct messages or private account data.
* User handles, display names, DIDs, profile metadata, or other direct account
  identifiers.
* Authentication secrets, API keys, access tokens, or other credentials.
* Raw interaction logs or account-level records.
* Any claim of ownership over third-party Bluesky content beyond the derived
  dataset files included here.
