Congressional Twitter Network Dataset Notice
===========================================

This notice applies only to the data files in
datasets/congress/congress_network/ and does not replace the software
licence for the code in this repository.

Provenance
----------

This dataset is a processed, derived representation of the Congressional
Twitter/X network described in:

* Fink, C. G., Fullin, K., Gutierrez, G., Omodt, N., Zinnecker, S.,
  Sprint, G., & McCulloch, S. (2023). A centrality measure for quantifying
  spread on weighted, directed networks. Physica A: Statistical Mechanics
  and its Applications, 626, 129083.
* Fink, C. G., Omodt, N., Zinnecker, S., Sprint, G. A Congressional Twitter
  network dataset quantifying pairwise probability of influence. Data in Brief
  (open-access article; CC BY-NC-ND 4.0).

The upstream project that accompanied this dataset is the public GitHub
repository gsprint23/CongressionalTwitterNetwork, whose software licence is
MIT. This notice is intended for the processed dataset distributed with this
repository and should be read together with any applicable upstream terms.

What is included
----------------

* A derived weighted, directed network representation.

What is not included
--------------------

* Tweet text or media.
* Direct messages.
* Private account data.
* Public-member identifiers, including handles, usernames, user IDs, or profile
  metadata.
* Authentication secrets or API keys.
* Any claim of ownership over third-party X/Twitter content beyond the rights
  held by the original authors and by X.

Redistribution and use
----------------------

The dataset distributed in this repository is a derived network representation,
not a redistribution of raw X/Twitter content. It does not include tweet text,
media, user identifiers, profile metadata, or other account-level records.
